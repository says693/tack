# 中文名候选

英文 `tack` 固定（repo、可执行文件、`data/tack/`）。中文名只影响界面标题与 README 首行。

| 候选 | 读感 | 与产品的关系 |
|---|---|---|
| **图钉**（推荐） | tútīng，两字都常用 | 「图」兼指图形与图谱；「钉」即核心动作。与 tack 直译对位，好念好搜 |
| 钉板 | dīngbǎn | 更贴"知识钉板"的整体定位，像一个容器名，动作感弱 |
| 拾钉 | shídīng | 「拾起 → 钉住」，最贴核心交互，读音略文气 |

决定后：改 `ui/*.html` 的 `<title>`、`README.md` 首行、`tauri.conf.json` 的 `productName`（保持英文可执行文件名不变）。
