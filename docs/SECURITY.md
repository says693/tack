# 安全披露

## 保护对象只有一件：API Key

学习笔记、导入的文件、生成的卡片都按**公开数据**处理，可以随意备份、分享。键只走两条通道：

1. 环境变量 `TACK_API_KEY` / `DEEPSEEK_API_KEY`（会话级，不落盘）；
2. Windows 凭据管理器，target = `tack/llm`。

`data/` 目录与整个仓库在 `.gitignore` 中排除，启动检查会提示仓库里是否出现疑似密钥文件。

## 前端

- CSP 只允许本地资源与 Tauri IPC（`connect-src ipc: http://ipc.localhost`），页面本身无法外联。
- 三个窗口无文件系统直通权限；Rust 侧只暴露 5 个命令（开窗、钉卡、关窗、取种子、切主窗）。

## 模型调用的暴露面

- 导入的原文会随出题请求发给配置的模型端点。**不要导入含有未脱敏个人信息的材料**；界面上的正则脱敏只是辅助，不是保证。
- 纯本地模式：不配置 `base_url`，所有环节走启发式，零网络请求。
- 模型返回内容按不可信处理，不执行其中的脚本或指令。

## 报告问题

在 GitHub 开 issue，标题以 `[SECURITY]` 开头；不要在公开 issue 中贴 Key。
