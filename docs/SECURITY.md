# 安全与隐私

## 数据

笔记、教材、卡片、作答均可能包含个人信息，不能默认视为公开资料。数据保存在本机用户目录的 SQLite 文件中，当前没有额外数据库加密；共享设备应使用操作系统账号隔离与磁盘加密。

在线模式会把所需原文或作答传给用户明确配置的 HTTPS 模型端点；默认离线模式不调用模型。请在启用在线模式前确认资料的授权与隐私边界。本产品不宣称具备自动隐私脱敏能力。

## 凭据

只接受 `TACK_API_KEY` 或系统钥匙串 service=`tack` / username=`llm`，不借用其他产品环境变量。Key 不写入数据库、不返给 UI、不在模型异常中拼接供应商响应。不要把 Key 写进配置文件或 GitHub issue。

## 信任边界

- 前端 CSP 限制为本地资源与 IPC。
- 不给前端直接文件系统或 shell 执行权限；文件选择与固定 sidecar 在 Rust 端调用官方插件。
- Python 请求按操作模型校验，写操作需要幂等请求 ID。
- 数据库使用参数绑定、事务与版本迁移。标准答案不被复习记录修改。
- 模型输出经 Pydantic 严格验证；认证、网络、JSON 或 schema 错误停止当前业务，不以近似答案掩盖失败。
- 文件导入有尺寸与块数上限，但不代表对恶意 PDF 的完整隔离。不要导入不可信来源的可疑文件。

## 发布

三种依赖锁文件进入 Git；CI 与发布使用锁定安装。GitHub Actions 引用不可变提交。安装包未签名，可能触发操作系统的未知发行者提示；不应关闭系统安全防护来绕过。

本次审计不是渗透测试认证，也不是所有依赖无漏洞的保证。
