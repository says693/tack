# 折页：用自己的 AI 准备课程，离线学

2026-11-18。以这份产品决定为准；[早期离线路线图](OFFLINE-LEARNING-ROADMAP.md)和 R3、`tack` 审计只供历史与技术参考。

**不预装固定课程。** 安装后开始的就是完整向导：连接自己的 AI、写下真正想学的科目、确认折页找到的可信资料、生成自己的本地课程，然后开始学。配置过程中不要求自己找教材、理解模型参数、写提示词或导入数据库。

## 首次打开

1. **连接 AI。** 默认走 DeepSeek。三步图文教程直接打开官方 API Keys 入口，引导登录或注册、创建并复制 API Key、回到向导粘贴并测试。教程用官方公开页面和新版 Windows 客户端空密钥框的实拍，不伪造登录后的界面。连接测试只查询账户状态，不调用生成模型，不发送学习主题或材料。验证后的 Key 存在当前用户的 Windows 凭据管理器，不写入学习 SQLite。没有可用额度也能先选科目；生成时报余额不足，可以打开官方充值页，再用原密钥重试。
2. **告诉折页想学什么。** 一处输入接受科目名和常见自然说法。若输入宽泛学科，界面在资料预览显示本次能教的范围；未覆盖的具体要求明确告知，不偷换课题或请求模型编一节无来源的课。
3. **确认资料与外发。** 展示折页提供的资料标题、参考发布方、范围、出处及实际摘要内容。用户确认后，才向明确显示的模型端点发送主题与选中资料。退出回到最靠近的可继续步骤；确认不会被记成长期许可或自动重发。
4. **生成并开始。** AI 根据已给材料整理讲解、短例、回忆题、答案与常见误解。折页校验结构及逐题原样证据，再用事务写入课程、来源快照与卡片。不接受 AI 给出的自由 URL、SQL 或假引用。不完整、超时或证据不匹配时留在生成环节，保留用户输入，不留下半节课。
5. **之后离线。** 再打开直接回到已生成课程，Key 失效或没网络不影响学习。讲一点、自己答、对照、自评。讲解和核对时可以展开生成时用过的完整资料笔记；答题时不提前展示答案或出处。到期才复习，草稿与进度在本地；未提交清楚区分已保存和待保存，提交首答后不能覆盖，重复确认不会重复排期。

## 信源边界

- 提供给模型的是原始材料或许可明确的自编摘要，不是课包。对每份资料留稳定 ID、参考发布方、出处链接、许可说明和所用文本；学习端离线仍可核对使用过的摘要。
- 精确摘录能验证 AI 没编造证据，不能证明生成的解释在事实和教学上全对。区分来源、折页摘要和 AI 整理内容，不能把对照页说成人工认证。覆盖范围按可核对材料扩展，不做「任何输入都能生成」的承诺。
- 当前[资料目录](../src-tauri/resources/study-sources.v1.json)覆盖物理（光的反射）、数学（一元一次方程）和 Python（控制流）三个专题。折页自编的事实摘要分别链接 NASA Science、Siyavula 和 Python 官方文档供核对。随包的是用来备课的资料，没有预生成的课程、题目或答案；在 Windows 向导授权并成功调用用户自己的模型之后才会有首节课程。

## 当前工程范围

- 一份本地库先支持新建一门课的首节和后续到期复习。已有资料库不改名、不覆盖；旧用户可明确进入新向导，并可返回以前的资料。旧版模型设置和新版向导的凭据不互用。
- 桌面向导目前只接 DeepSeek，隐藏 Base URL 和模型参数。后续接更多用户自带的兼容模型时，密钥与外发同意按端点隔离，不把旧 Key 发送到换过的地址。
- 普通窗口和一个主动作取代强制胶囊、空书架、模型设置大盘。先完成首启与学习本身；旧聊天分叉、统计、预算面板不进入这条流程。
- 浏览器开发预览用明确标注、零外发的测试替身。旧工作台的样例载入只在浏览器开发预览可用，不写进用户的桌面库。原生验收脚本用一次性目录及测试夹具验证续学；夹具不进入安装包，也不代表真实生成。

## Windows 候选包

`npm run tauri:installer` 构建中文、当前用户安装的 NSIS 安装包，位于 `src-tauri/target/release/bundle/nsis/`，内含 WebView2 安装程序。`npm run tauri:build` 只生成 `src-tauri/target/release/fold.exe`；可在已有 WebView2 的机器直接打开。

`node e2e/native-onboarding-smoke.mjs` 使用独立临时数据目录运行原生 EXE，核对空库首屏及教程，注入仅在测试脚本中的课，再重开客户端验证本地草稿和复习。不访问实际用户库，不输入真实 Key。

2026-11-18 本机候选：`折页_0.1.0_x64-setup.exe`（221.14 MiB，未签名），SHA-256 `F2F87E31FDF5AE087CCEB3814FB8747A0E3CF045E0DFE1FEE94C7BE1897F9A6D`。同次构建的 `fold.exe` 已通过原生首启、窄窗口、跨进程恢复、保存完整资料笔记和到期复习验收；外部 WebView 请求在测试中被阻断。Rust 48 项、前端单测 14 项、浏览器回归 8 项通过。未验真实账号生成及干净 Windows 安装。

## 发布关卡

1. **从安装走起。** 用干净的 Windows 账户运行中文安装包；分别验证没有和已有 WebView2 时的启动，再逐步完成官方平台注册/登录与连接。公开发布前签名。教程只用真实、脱敏截图；没有取得的登录后截图用官方入口和文字，不造假。未使用真实 Key 的本地测试不算完成这一步。
2. **让新人自己选。** 不经口头指挥，至少选择两个不同的支持科目完成生成，用获授权的测试账户验证实际模型输出、授权范围、费用失败和坏响应。随机覆盖一次不支持的主题：不能发起生成。
3. **关网继续。** 用同一版本在实际保存课程后断网、结束进程并重开，验证原课、草稿、已提交答案、双击确认和第二天到期复习；旧库单做回归。通过这一全流程才称为可交付，不以预装一课或浏览器截图代替。
4. **扩展可信资料。** 优先补用户最想学的范围及连续课节，再考虑更多模型；继续对每个内容范围留出处、可校验摘要及失败保护。不给用户增加一套备课后台。
