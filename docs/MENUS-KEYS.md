# 交互与键位

- Enter：提交当前答案；已看到结果时进入下一张。
- 输入框内 Ctrl+Enter：提交答案。
- Space：查看提示，不替换未提交草稿。
- N：进入下一张当前到期卡。
- S：安排明天复习。
- L：安排今天 20:00；已经过时则明确报错，不偷偷排到另一时间。
- P：从当前原文打开锚点。
- ? / F1：原生 HTML 对话框键位表。
- Ctrl+Shift+T：系统全局唤出/收起主窗。
- Esc：关闭当前对话框；锚点中关闭未提交内容。

菜单或对话框开启时不会触发背景复习快捷键。主窗草稿按科目与卡片 ID 保存于当前进程，切换卡片和科目不会丢失；草稿不承诺跨应用退出保存。

HUD 的钉头区域用于拖动，中间按钮开合主窗，“菜单”及右键使用 Tauri 原生弹出菜单。主窗右键提供原文钉卡、今晚、明天、暂停；暂停卡可在科目管理恢复。
