# 右键菜单与快捷键

设计原则：右键是"就地决定"，快捷键是"过卡不离开键盘"。菜单里每一行都标注对应键位，学会一次就能全部不用鼠标。

## 主窗 · 卡片右键

| 行 | 键位 | 做什么 |
|---|---|---|
| 钉住这张卡 | P | 一句话提炼 + 原文钉成卡，明天先回看 |
| 现在练习一次 | Enter | 清掉本轮批改重答 |
| 今晚再看 | L | 今天 20:00 再出现 |
| 跳过这张 / 明天再来 | S | 挪到明天 |
| 放下这张卡 | — | 危险动作，朱红；不删数据，只是移出今天 |

## 主窗 · 空白右键

拖入教材开始导入、键位表（?）、回到今天开头（Ctrl+N）、收窗。

## 主窗 · 科目标签右键

列出全部科目，当前科目左侧有一条朱红细印；底部一条灰行提示 Ctrl+Tab。

## 锚点窗右键

复制原文（C）、改名后再钉（F2）、钉住并关闭（Enter）、丢弃（Esc，朱红）。

## HUD 右键

打开今日（Ctrl+Shift+T）、回到右下角、钉在屏幕最上层（可勾选）、退出 tack。

## 快捷键总表

主窗：Space 提示 · Enter 交卷/下一张 · 输入框内 Ctrl+Enter 交卷 · S 跳过 · P 钉住 · L 排今晚 · C 复制 · Ctrl+Tab 切科目 · Ctrl+N 回开头 · ? 或 F1 键位表。

锚点窗：Enter 钉住 · Esc 丢弃 · F2 改名 · C 复制原文 · Ctrl+W 丢弃。

全局：Ctrl+Shift+T 随时唤出/收起主窗（Tauri 全局热键，任何程序前都生效）。

## 键盘导航

右键菜单支持 ↑ ↓ 选择、Enter 确认、Esc 关闭；键位表 Esc 关闭。所有焦点可达元素都有可见 focus 环。
