# Tier 1 信源清单（人工策展）

原则：只从这里取材料，**不让 AI 爬全网、再让 AI 审成"权威出处"**——那会把幻觉洗白成引用。

| 领域 | 信源 | 许可 / 获取 |
|---|---|---|
| 通识 · 数学 · 物理 · 化学 | OpenStax 开放教材 | CC BY 4.0，openstax.org 直接下载 PDF |
| 通识 · 理工 | MIT OpenCourseWare | CC BY-NC-SA，ocw.mit.edu 讲义与习题 |
| 计算机 | MDN Web Docs | CC BY-SA 2.5（正文），developer.mozilla.org |
| 系统操作 | ArchWiki | GNU FDL / CC BY-SA 双许可，wiki.archlinux.org |
| 哲学 | Stanford Encyclopedia of Philosophy | 查阅免费；引用遵守 SEP 条款 |
| 高中/大学（中文） | 智慧高教公开课 | 以平台条款为准，仅取个人学习可用材料 |
| 公版文学 | 中国哲学书电子化计划 / Project Gutenberg | 公版区；Gutenberg 按地区核对版权 |
| 生物 / 医学基础 | NCBI Bookshelf | 部分条目 CC BY；逐条核对 |

## 使用规则

- 导入前确认许可允许个人学习与再分发片段；仓库只存元数据与用户自建的卡，不内置教材正文。
- 卡的 `source` 字段记录：书名、章节、页或 URL。答错时"错在哪"才能指回原文。
- 不确定版权的一律不导入。宁可少一张卡，不进一份可疑材料。
