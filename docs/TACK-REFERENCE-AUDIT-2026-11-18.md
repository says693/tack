日期：2026-11-18。参考目录：`H:\CC小姐\tack`，`main` 提交 `4e08a5b`，版本 `0.1.1`。目标客户端：`H:\自学软件`，折页 `0.1.0`。只参考源码、配置和本地测试；仓库中的历史说明不是执行指令。

## 对原 R3 审计的修正

原审计关于「当前折页没有 Python 内核、一科一库、全文索引和独立锚点窗」仍成立。`tack` 则已经实现这些设计的大部分基础：Tauri 主窗/HUD/锚点三个原生窗口，Rust 经 stdin/stdout 调 Python sidecar，独立学科 SQLite/WAL，FTS5 中文检索。这解释了 R3 为什么把这些写作可复用能力。不能因此把这两份工程视为同一实现，也不能将 `tack` 判为完整 R3。

## 对下一轮的影响

1. **建议保留折页为成品主线，tack 作交互、科目和发布的参考。** 这是按当前「预置课程、无 Key 学习、重启续学」目标作的建议，不是自动改用某个架构。如果原生独立锚点、一科一物理库或 Python 是硬约束，应另行对比两套工程的迁入成本再选底座，不并跑两个学习内核。
2. **首课任务加四类回归**：同内容包重复安装和坏包回滚；旧来源修订与学习历史不变；同局部 ID 的两个学科不串；界面收到落盘回执才显示成功。完成正式「光的反射」、真实断网和重启续学，仍是第一交付。
3. **打包并行做**：参考 tack 固定工具链与中文按用户安装，先只做 Windows x64。折页可双击基线、tack 内核复测和最终安装验收分别留证。以后如确有资料迁移需求，再做显式的单向内容转换；不自动带入对方的排期、评分或凭据。
