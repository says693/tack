# 折页：从可启动 EXE 到 Windows 成品

> 本页保留上一轮的背景、历史构建和技术验收参考。新版范围、优先级与发布关卡以[引导式离线学习计划](GUIDED-LEARNING-NEXT.md)为准。

更新：2026-11-18。[R3 审计](R3-AUDIT-2026-11-18.md)记录折页的原有差距；[tack 本体对照](TACK-REFERENCE-AUDIT-2026-11-18.md)补充了规划所对应的另一套实现及本机复测。附件是验收参考，不是要求照搬其架构。预置课程与 R3 的手工学习链分别验收，不以 Windows 成品标签代替完整 R3 的通过证据。

## 当前可启动版

本机已用 `npm.cmd run tauri:build -- -- --offline --locked` 生成 [`fold.exe`](../src-tauri/target/release/fold.exe)（`0.1.0`）。把单个 EXE 放进空的临时目录启动，在真实 Windows/WebView2 中用临时库跑通欢迎页、教程图片、提交试学答案和进入书架。页面加载自内嵌资源，拦截 WebView 外部请求，测试未观察到外部请求；无 Key，来源、卡片、分配、尝试及复习均为 0。没有访问学生库或调用模型。

SHA-256：`EA0CC2EFFA2A6511F698E53ADE62C387D75490365883AAEE638ADDD22A19015E`。这是未签名的本地基线，要求已有 WebView2；不是安装包，未证明系统级断网或干净机离线安装。当前版本不应拿来保存生产 Key 或学生唯一资料。

## 产品主线

**先在线备课，后离线学习。** 首批由项目方选定学科和范围，AI 辅助生成讲义、概念、卡片与出处，经校验和人工核对后随客户端发一课。学生打开客户端便能学，不注册、不填 Key、不等待现场生成。随后复用同一格式加「输入学科 → 在线备课」入口，才让用户自行生成新课。导入自己的 MD/TXT 和手写卡保留，走同一套本地作答、记账与续学规则。

**三种入口各做一件事**：`先试一下` 是现有的短教程，不写个人记录；`开始第一课` 进入真正的离线学习；`获取 DeepSeek API Key` 留在设置及在线备课，需要时可打开和返回，不阻断首启。沿用已取得的官方文档与 Windows 客户端实机截图；需登录的管理页没有真实、脱敏截图之前，只用官方入口和文字说明。以后补图不应从真实密钥显示页面直接截取。

**Windows 1.0 定义**：拿到一个安装包，普通学生不需要开发环境、账号、网络或 Key，就能打开一套小课程、保存复习并隔天续学；也能导入自己的文本、手写卡、备份和恢复。首发内容建议限定为「初中物理 · 光学入门」一个完整小单元，4–6 节短课，每课 3–5 个概念，不宣称覆盖全学科。项目方的 AI 备课产线和首发内容是交付项；客户端自助备课只在外发与凭据关卡通过时启用，否则明确标为离线版，未启用能力不算完成。暂不做 PDF/OCR、整本自动出题、账号同步、多平台或双窗改造。

| 0 · 可启动基线 | 本机发布构建可双击，记录版本、SHA-256 和已验范围；下一轮建立源码基线和可重复打包脚本。 | 当前 EXE 启动冒烟已通过；安装包、干净机和签名仍待做。 |
| 1 · 一课能学（Alpha） | 冻结内容包、课节入口、续学与回执；保留 React、Tauri、Rust、SQLite 与现有调度。把 `光的反射` 从只供体验扩为一节正式课，3–5 个概念各一张主卡。默认从普通窗口开始，任务栏能找回；置顶和胶囊留作自选。 | Windows 真实应用断网、零 Key 跑通。退出进程后回原课、原题和阶段；答前不泄答案，重复确认只有一次记录和排期。每一轮都给可点击的桌面产物。 |
| 2 · 真资料也能用（Beta） | 手工导入、手写卡、自评、无额度随手练；补手工草稿续学、队列和演示隔离。恢复包不含密钥，带受管原件、未完作答与回执。 | 手工链单独通过；含未合并 WAL 变更的数据库可从快照恢复，坏包不动原库。真实旧库迁移前消除凭据明文和迁移、备份泄漏。 |
| 3 · 做成可扩写的课程 | 先做一节独立编写的第二课，再并行制作首发小单元。教纲和可分发资料先定；AI 给草稿，校验结构和原文，内容负责人核对事实、题答、出处与许可，人工批准后发布同一格式的内容包。 | 每课有讲解、例子、回忆卡和可核对出处；无可信来源的内容标待核，不编引用、不发布。离线安装内容包不修改既有学习历史。 |
| 4 · 可选在线备课 | 学科输入默认带水平和单课范围。预览实际外发文本和端点、明确同意后才生成一课草稿；预览、编辑、确认后用同一个导入器安装。实机 Key 教程在需要时打开。 | 凭据进系统安全存储；未确认、发出前取消、端点变化未重授权均不发送。失败、未知状态和迟到响应不自动重试或发布。先跑受控服务，再用获授权材料实测；安装后关网照学。 |

## 第一轮的共同契约

- **V0 内容包**：先用 UTF-8 JSON，包含 `schemaVersion`、包 ID、学科 ID、包版本、课节、概念、卡片和证据锚点。用稳定 ID 引用固定材料修订中的原文与出处，不接受任意 SQL 或直接导入 SQLite。内容包不含答题、书签、排期、用户设置或 Key。区分作者资料、AI 新编和人工核对；引用可定位不代表内容一定正确。
- **导入只写内容**：宿主校验大小、格式、重复 ID、悬空引用及原文锚点，事务导入；复用 `source/source_revision/chunk` 和 `concept/card/card_revision`。同包同版本同摘要重装无变化；同版本不同摘要拒绝；V0 不做自动跨版本覆盖。安装和预览不自动领题、占用额度或写复习。导入 AI 草稿不等于自动收下。
- **持久化由宿主负责**：检查点记学科、课节、材料修订、阅读位置及当前尝试；答题阶段从已落盘的尝试和回执读取，避免维护两份状态。保留最近已保存的作答草稿；首答提交后不可覆盖，`想不起来` 独立记录；题面响应不含参考答案，首答落盘后才返回对照。正式题确认写入一条复习与可查询回执；遇到回包丢失先查原回执，不再派题。
- **课内不串题**：当前全局队列会优先返回当天已有未完成题。课内入口要按本课范围挑选，指定题失效时不能回退至全局随机选题；发现别课未完成题时明确提供返回入口。课程开始前不把卡暴露给全局新题领取；正式领取遵守同一日预算。跨日续学按原尝试 ID 加载，不靠当日筛选、不重扣额度；确认后的卡走现有到期队列。
- **借 tack 的科目与回归用例，不合并数据库**：首课也从第一天带稳定学科 ID。用两个学科含同局部 ID 的夹具，加重装、改版保留旧出处、失败整批回滚与已保存反馈的回归。FOLD 保留自己的尝试、复习、排期和数据目录。
- **迁移与界面不能虚报**：现有数据库初始化和升版不能只改版本常量；新库与旧库迁移都要跑到同一结构，迁移失败回到原状态。迁移前快照当前会复制密钥，在真实旧库上运行新迁移前必须收口这条路径。界面区分未保存和已保存；正常退出先等保存回执，异常终止只承诺恢复到最近一次成功保存的状态。

## 首轮分工与交接

| 负责人 | 并行工作 | 交接物 |
| --- | --- | --- |
| 主 agent | 冻结共享契约，统一 `db.rs` 的迁移顺序、`commands.rs` 注册和 TS 类型；负责合并、原生运行与发布判断。 | 一份契约、一个基线提交或可追溯快照、集成记录。 |
| 内容与入库 agent | 实现样包校验、原子导入和课节/材料关联；使用虚构旧库验证现有来源、卡与学习记录不丢失。 | 内容包模块、事务及幂等测试、迁移所需改动清单。 |
| 学习与续学 agent | 实现课节入口和「继续上次」；接现有 Reader、Review 与 Today，落盘检查点，处理离线自评和跨日续学。 | 客户端流程、续学模块及状态转换测试。 |
| 样课与验收 agent | 核对样课的讲义、题答、来源和许可；扩充坏包、零外发、重复确认与真实重启脚本。 | 已核校样包、测试夹具和明确的验收记录。 |

每轮先锁共享类型与测试夹具，再并行改各自文件；`db.rs`、`commands.rs` 与共用类型的冲突由主 agent 合并。按「样包导入 → 课节阅读 → 作答落盘 → 回执恢复 → Windows 真机」顺序集成。发布工作独立走 Windows 构建与验收，不等所有功能完工才第一次装包。每轮只领当前关卡的缺口；实测问题回到对应负责人修复和复测。

## 第一课的验收细则

1. **首次打开**：断网、无 Key，教程试学不创建个人作答、复习或分配。显式开始正式课后可读讲义；内容包资源本地可用，应用出站请求为零。旧「载入示例材料」入口不可再悄悄把演示混进正式书架；不自动删除已有记录。
2. **退出续学**：分别在阅读、未提交作答、首答已提交待确认时退出进程再开，回原课和阶段。窗口关闭可能只是隐藏，应使用托盘退出或受控终止验证真实重启；补测跨日、已有别课题和保存失败，不覆盖首答。
3. **恰好一次**：未确认时正式复习数不增；确认后恰好新增一条复习并推进一次排期。模拟事务成功但回包丢失，可查回原收据；同键不同载荷、过期版本或未处理异议不可再次写入。
4. **坏包不动库**：重复装合法包不产生重复；改坏最后一张卡、证据越界、包内 ID 重复、未知格式版本，都无部分写入。与两个不同学科中同局部 ID 的夹具对照，确认不会串课或覆盖个人历史。

浏览器 Playwright 只验界面，Rust 临时文件库验事务和并发，Windows 真实进程验落盘、重启与出网。三种证据分开记。先用可丢弃资料；任何未授权外发、重复计分、首答覆盖或坏包覆盖好库都阻断扩大试用。

## 发布与回退

- **可复建**：先审查工作区，排除密钥、个人数据库和本地安装产物，再建立 Git 基线。对齐应用、安装器、锁文件的版本和源码标签，记录 Node/npm、Rust/MSVC/SDK 和构建命令；在干净 Windows 环境验证不依赖此机的镜像或缓存。
- **可安装**：用 WebView2 `offlineInstaller` 方案准备候选包，不能把当前 `downloadBootstrapper` 配置当成离线安装。验系统任务栏/开始菜单、键盘、中文输入和高 DPI；记录浏览器运行时版本及目标 Windows 范围。未签名产物只供内部验收，公开包核验安装器和应用签名、时间戳、素材与依赖许可及 `NOTICE`。
- **可回退**：升级前确保旧进程完全退出且不会有第二个写入者；验证不含凭据的预升级备份。用旧版格式测试升级与受控失败；回退使用旧版软件和经验证的隔离恢复副本，保留原目录。卸载默认保留个人学习资料，并明确显示此行为。
- **学生能用**：建议请 5 位没用过的学生自行安装、学习一节课并隔天续上，目标至少 4 位不经口头提示独立完成。完整 R3 另按 A00–A36、R3-01–07 逐项留证，包括非敏感真实材料至少 5 个概念、10 次尝试和真实模型专项。发布记录列出已验证、失败和仍未验证的场景，不混用浏览器模拟、实机和真实模型证据。
