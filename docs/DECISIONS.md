## 2026-11-15 · G0 骨架定稿

- **颜色不再走"黑底+霓虹"或"暖米+衬线高反差"**：两者都是 AI 生成页面的默认脸谱。取纸与墨——暖白纸面 #F3F0E8、近黑墨 #1E1C19，唯一重色朱红 #B5432A 只出现在"钉头"：HUD、锚点、当前卡三处。色彩因此有语义。
- **零圆角卡片、2px 层级色柱**：知识层级（T1 深墨 / T2 灰 / T3 苔绿）是信息，不是装饰；卡片的身份由它承担，而不是阴影。
- **锚点窗只读**：分叉窗若像聊天框，用户会觉得"必须回复"，破坏阅读心流。按钮只保留 [X 丢弃] / [PIN 钉住]，追问再显式转对话。
- **中文检索用 FTS5 trigram**：不依赖中文分词器，子串即可命中；短查询退 LIKE。500 页级材料无需向量库。
- **PDF 用 pypdf**：PyMuPDF 是 AGPL，不适合 MIT 开源仓库；扫描版在 G1 用视觉兜底。
- **离线优先**：没有 API Key 时出题、批改、调度全部走本地启发式，闭环照样跑通；模型是增强，不是前提。
- **密钥只进凭据管理器**：环境变量 → Windows 凭据管理器（`tack/llm`），`data/` 与仓库零密钥。
